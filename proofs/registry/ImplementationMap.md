# Registry implementation map

This guide maps selected Rust execution paths to the Rocq model of
owner-controlled Data updates after successful initialization. Each entry
links to the relevant Rust statements and their Rocq counterparts. The mapping
is a manual review. The Rocq proofs establish results about modeled executions
under supplier contracts. A refinement proof would also have to show that the
Rust implementation produces those executions and satisfies those contracts.

The [component theorem](theories/composition/OwnedDataComponent.v#L89)
establishes the [public signature](theories/interface/OwnedDataContract.v)
for admitted calls. See the [component contracts](Components.md) for supplier
obligations and the [verification commands](README.md#reproducing-the-checks)
to compile and check the proof.

## Unchanged Data returns without opening a scope

**Rust.** [`write_registry_data_objects`](../../kernel/firmware/src/selected_app.rs#L3123)
checks the request and compares generated bytes with existing Data before
opening a registry operation. [The comparison loop](../../kernel/firmware/src/selected_app.rs#L3137)
retains original producer indices and treats repeated tags as replacements.
The [zero-change return](../../kernel/firmware/src/selected_app.rs#L3154)
precedes payload preparation, attachment, and publication.

**Rocq.** [`owned_unchanged_then_published_from_body`](theories/verification/OwnedDataWitnesses.v#L142)
composes an unchanged call with a later successful, changed call. The first
call returns without a publication receipt. The second produces an exact
receipt for its publication.

**Open obligation.** Relate the Rust lookup and comparison, including duplicate
tags and producer indices, to the prepass contract. The theorem assumes the
modeled comparison response for the first call.

## Local body error rolls back before returning

**Rust.** [`run_operation`](../../kernel/firmware/src/registry/transaction.rs#L112)
opens a local scope and passes the body's success flag to
[`OperationScope::finish`](../../kernel/firmware/src/registry/savepoint.rs#L68).
On body error, the scope takes
[`rollback_pending`](../../kernel/firmware/src/registry/savepoint.rs#L76)
and skips owned-transaction finalization. A pending savepoint is consumed
before restoration. For an owned transaction, the armed
[`TransactionOwner` guard](../../kernel/firmware/src/registry/transaction.rs#L99)
then runs outer rollback on scope exit.

**Rocq.** [`owned_marked_local_cleanup_returned`](theories/internal/transactions/FreerRecycledWriter.v#L7665)
derives `ReturnedBodyError` at a `Ready` registry with an `IdleBoundary` from
the admitted body failure, restoration, and collection premises.
[`owned_local_error_then_published_from_body`](theories/verification/OwnedDataWitnesses.v#L598)
uses that path in a two-call witness where the next call publishes.

**Open obligation.** Relate the Rust guard execution, restoration, and
collection to the modeled cleanup path. The result covers ordinary error
delivery under its premises. Frozen, fatal, and reset paths have separate
outcomes.

## Journal publication and reset recovery

**Rust.** [`publish_persistent_registry_after_mutation`](../../kernel/firmware/src/registry/publication.rs#L41)
reuses or writes a registry snapshot (BOSS). A new authority is recorded by
[`journal::append`](../../kernel/firmware/src/registry/journal.rs#L135).
The [publication caller](../../kernel/firmware/src/registry/publication.rs#L74)
updates its volatile state after append returns successfully. After a reset,
[`restore_persistent_registry_if_available`](../../kernel/firmware/src/registry/recovery.rs#L16)
selects the journal's durable root, restores the compact image, and rebuilds
runtime state and page ownership.

**Rocq.** [`episode_success_durable`](theories/internal/transactions/FreerGlobalDataTrace.v#L4096)
preserves the published offset, decoded image, and certified bytes after a
delivered success, provided there is no later physical publication and
recovery reaches `Usable`.
[`episode_uncertain_no_hybrid`](theories/internal/transactions/FreerGlobalDataTrace.v#L4155)
allows recovery to select either complete certified candidate when publication
was uncertain, under its certification and recovery premises.

**Open obligation.** Establish the concrete journal, flash, and decoding
contracts, and relate Rust's selected root and reconstructed state to
`Usable`. A physical journal publication can occur before the caller receives
success. The results are conditional on completed recovery.

## Scope limits

The map covers the modeled owner-controlled Data path. Interrupted bootstrap,
streaming LOAD, joined operations with an active parent, and other registry
users have separate obligations. The relation between bytes requested by a
Rust Data callback and bytes recovered from flash remains open. The proof
gives no unconditional termination or capacity guarantee.
